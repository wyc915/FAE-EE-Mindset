# 04. FAE 產品線實務（一）：電源 IC

> **一句話**：電源 IC 是 FAE 需求量最大的產品線之一。客戶問題集中在**效率、漣波、暫態響應、迴路穩定、散熱與 EMI**；FAE 要能算元件、看 Bode 圖、量波形，並給出具體的修改建議。

## 學習目標

- 認識電源 IC 產品家族與各自的應用場景
- 會用公式估算 Buck 轉換器的電感、輸出電容與輸入電容
- 理解控制架構（電壓模式、電流模式、COT）與輕載模式（PFM / PWM）的取捨
- 能判讀迴路穩定性（相位裕度）並用負載暫態測試驗證
- 熟悉常見客訴：振盪、啟動失敗、嘯叫、過熱、EMI
- 了解充電 IC、USB PD 與 AI 伺服器多相電源的趨勢

> 前置知識：[第 02 章](02-fae-technical-foundation.md)的 LDO vs DC-DC 與電源除錯。

## 1. 電源 IC 產品家族 🟢

| 產品 | 功能 | 典型應用 |
|---|---|---|
| **LDO** | 線性降壓，低雜訊 | ADC 參考、RF、感測器 |
| **Buck** | 切換式降壓 | 幾乎所有數位電源軌 |
| **Boost** | 切換式升壓 | 單節電池升壓、LED 背光 |
| **Buck-Boost** | 輸入可高於或低於輸出 | 電池供電、USB PD |
| **PMIC** | 多路電源整合，含上電順序控制 | 手機、SoC 平台、SSD |
| **充電 IC（Charger）** | 電池充電、電源路徑管理 | 手機、筆電、穿戴 |
| **Load Switch / eFuse** | 電源開關、限流、熱插拔保護 | 伺服器、儲存設備 |
| **多相控制器 + Power Stage（DrMOS）** | 大電流 CPU / GPU 核心電源 | 伺服器、AI 加速卡、主機板 |
| **Gate Driver / PFC / Flyback 控制器** | 交流轉直流、隔離電源 | 變壓器、充電器、工業電源 |
| **LED Driver** | 定電流驅動 | 照明、背光 |

> 台灣有不少電源 IC 公司（例如立錡、茂達、致新、力智、矽力杰），外商有 TI、ADI、Infineon、onsemi、MPS 等，加上代理商，FAE 職缺很多。

## 2. 規格書重點參數 🟢

| 參數 | 意義 | FAE 注意 |
|---|---|---|
| **Vin 範圍 / Iout** | 輸入電壓與輸出電流能力 | 留餘裕，注意**溫度降額** |
| **效率曲線** | 不同負載下的效率 | 輕載效率看 PFM、重載看導通損耗 |
| **Iq（靜態電流）** | 無負載時 IC 自身耗電 | 電池產品待機時間的關鍵 |
| **Fsw（切換頻率）** | 開關速度 | 高頻元件小，但切換損耗與 EMI 上升 |
| **Line / Load Regulation** | 輸入或負載變化時輸出的變動 | 靜態精度 |
| **Dropout（LDO）** | 能穩壓的最小壓差 | 電池放電末端 |
| **PSRR（LDO）** | 抑制輸入漣波的能力 | 頻率越高通常越差 |
| **保護功能** | UVLO、OCP、OVP、OTP、SCP | 了解觸發後是**閂鎖**（Latch）還是**打嗝**（Hiccup）重試 |
| **Soft-start** | 開機時緩慢上升輸出 | 太短容易觸發 OCP，太長影響開機時序 |

## 3. Buck 轉換器設計計算 🟡

```mermaid
flowchart LR
  VIN[Vin + 輸入電容] --> HS[上管 MOSFET]
  HS --> SW((SW 節點))
  LS[下管 MOSFET] --> SW
  SW --> L[電感 L]
  L --> VOUT[Vout + 輸出電容]
  VOUT --> FB[回授電阻分壓 → FB]
```

| 項目 | 公式（連續導通模式，估算用） |
|---|---|
| 責任週期 | `D ≈ Vout / Vin` |
| 電感漣波電流 | `ΔIL = (Vin − Vout) × D / (L × Fsw)` |
| 選電感 | 讓 ΔIL 約為 **Iout 的 20～40%** |
| 電感峰值電流 | `Ipeak = Iout + ΔIL / 2`，**電感飽和電流 Isat 必須大於 Ipeak**（並大於 IC 的限流值更保險） |
| 輸出電壓漣波 | `ΔV ≈ ΔIL × (ESR + 1 / (8 × Fsw × Cout))` |
| 輸入電容 RMS 電流 | `Irms ≈ Iout × √(D × (1 − D))`，D = 0.5 時最大 |
| 回授分壓 | `Vout = Vref × (1 + R1 / R2)` |

**計算範例**：Vin = 12V、Vout = 1.2V、Iout = 5A、Fsw = 500kHz、L = 2.2µH
- D = 0.1，ΔIL = (12 − 1.2) × 0.1 / (2.2µ × 500k) ≈ **0.98A**（約 20% Iout）
- Ipeak ≈ 5 + 0.49 ≈ **5.5A** → 選 Isat ≥ 7A 的電感
- 若 Cout = 2 × 22µF MLCC（考慮 DC Bias 後實際約 30µF）、ESR 約 2mΩ：ΔV ≈ 0.98 × (0.002 + 1 / (8 × 500k × 30µ)) ≈ **10mV**

> 實務上先用原廠的**設計工具或計算表**，再用公式檢查合理性；客戶亂改電感或電容是常見問題來源。

## 4. 控制架構與輕載模式 🟡

| 架構 | 特性 | 優點 | 缺點 |
|---|---|---|---|
| **電壓模式** | 比較輸出電壓與鋸齒波 | 雜訊敏感度低 | 補償較複雜、暫態較慢 |
| **峰值電流模式** | 內迴路控制電感電流 | 補償簡單、逐週期限流 | D > 50% 需斜率補償 |
| **COT / 漣波控制** | 固定導通時間，依需求觸發 | **暫態響應極快**、補償少 | 頻率會變動，有時需輔助漣波注入 |

| 輕載模式 | 行為 | 取捨 |
|---|---|---|
| **PFM / PSM（省電模式）** | 輕載時跳脈衝，降低切換次數 | 輕載效率高，但**漣波較大、頻率不固定**，可能落入音頻造成嘯叫或干擾 RF |
| **FPWM（強制 PWM）** | 永遠固定頻率 | 雜訊可預測、漣波小，但輕載效率差 |

> 客戶抱怨「輕載時嘯叫」「RF 靈敏度在待機時變差」時，第一個要確認的就是是否進入 PFM。

## 5. 迴路穩定性 🔴

- **Bode 圖**：看開迴路增益與相位
  - **穿越頻率（Crossover, fc）**：增益 = 0dB 的頻率，常設計在 **Fsw 的 1/10～1/5**
  - **相位裕度（Phase Margin）**：fc 處的相位距離 −180° 的餘裕，一般要求 **≥ 45°**（常見目標 45～60°）
  - **增益裕度**：相位 −180° 處的增益，要求低於約 −10dB
- **量測**：在回授路徑串一個小電阻（如 10～50Ω）注入訊號，用頻率響應分析儀量測
- **沒有儀器時**：用**負載暫態測試**觀察——輸出過衝後振鈴次數多、衰減慢，代表相位裕度不足

| 暫態響應樣子 | 判斷 |
|---|---|
| 一次下陷後平滑回復 | 穩定、裕度足 |
| 下陷後振盪多次才停 | 相位裕度不足 |
| 持續振盪 | 不穩定 |
| 下陷很深但不振盪 | 頻寬太低或輸出電容不足 |

> 常見陷阱：客戶把 MLCC 換成更大的電容「想讓它更穩」，結果改變了 LC 雙極點與 ESR 零點，反而不穩。

## 6. Layout 要點 🟡

1. **熱迴路（Hot Loop）最小化**：輸入電容 → 上管 → 下管 → 回到輸入電容的迴路面積越小，振鈴與 EMI 越低。輸入小電容要**緊貼 IC 的 VIN 與 GND 腳**
2. **SW 節點面積小**：它是最強的雜訊源，但要足以承載電流
3. **FB 走線遠離 SW 與電感**，回授分壓電阻靠近 IC，取樣點接在**輸出電容處**（遠端感測時用 Kelvin 連線）
4. **散熱**：Exposed Pad 下方打散熱孔、加大銅面
5. **地**：功率地與訊號地在單點連接（依原廠建議）

## 7. 常見客訴與排查 🟡

| 現象 | 可能原因 | 排查 / 對策 |
|---|---|---|
| 輸出振盪 | 補償不當、輸出電容種類或容值改變、Layout | 量 Bode 或負載暫態；回到參考設計的 L、C |
| 開機失敗 / 打嗝 | 輸出大電容或重負載導致 **Soft-start 期間觸發 OCP** | 加長 Soft-start、確認負載開機時序 |
| 預偏壓（Pre-bias）開機異常 | 輸出已有殘餘電壓時下管拉低 | 選支援 Pre-bias 啟動的 IC |
| 嘯叫 | PFM 落入音頻、MLCC 壓電效應 | 改 FPWM、換電容種類或封裝 |
| 效率低 | 電感 DCR 太大、Fsw 太高、MOSFET 損耗 | 量各點溫度、換電感、調整頻率 |
| 過熱關機 | 負載超出、散熱不足、OTP | 熱像儀、計算損耗與 θJA |
| EMI 超標 | 熱迴路大、SW 振鈴 | 縮小熱迴路、加 RC Snubber、展頻（Spread Spectrum）、Boot 電阻放慢上管切換 |
| 電感飽和 | Isat 不足、高溫下 Isat 下降 | 量電感電流波形是否出現尖峰 |
| 輸出精度不準 | 回授電阻精度、FB 走線被干擾 | 用 1% 以內電阻、改 Layout |

## 8. 充電 IC 與 USB PD 🟡

- **鋰電池充電**：預充（Pre-charge）→ **定電流（CC）**→ **定電壓（CV）**→ 截止
- **JEITA**：依電池溫度調整充電電流與電壓，避免低溫或高溫時充電造成危險
- **Power Path**：插電時系統直接由輸入供電，同時充電；電池沒電也能立即開機
- **USB Power Delivery**：USB-C 上協商電壓與電流，USB PD 3.1 的 **EPR** 最高到 48V / 240W；**PPS** 可微調電壓，用於快充
- 常見問題：協商失敗（CC 線、韌體版本、線材 E-Marker）、充電過熱降速、電池保護板誤動作

## 9. AI 伺服器電源趨勢 🔴

- GPU / AI 加速器核心電流可達**上千安培**，使用**多相（Multiphase）Buck**：多個相位交錯切換，降低漣波並分散熱
- **48V 供電架構**：機櫃以 48V（甚至更高）配電降低電流損耗，板上再降到核心電壓
- **PMBus / 數位電源**：透過數位介面讀取電壓、電流、溫度並調整參數，由 BMC 監控（軟體背景在此有優勢）
- **GaN / SiC**：GaN 適合高頻、小體積（快充、伺服器電源），SiC 適合高壓大功率（電動車、太陽能）

## 動手練習

1. **計算練習**：Vin = 5V、Vout = 3.3V、Iout = 2A、Fsw = 1MHz，選電感使 ΔIL 為 30% Iout，計算 L、Ipeak 與所需輸出電容（目標漣波 < 20mV）。
2. **工具比對**：用 TI WEBENCH 或 ADI LTspice 模擬同一顆 Buck，比對你的手算結果，並觀察負載暫態波形。
3. **PFM vs PWM 實驗**：用一塊可切換模式的 Buck EVB，量測 10mA 負載時兩種模式的輸出漣波與輸入電流。
4. **讀 Application Note**：挑一篇原廠的 Buck Layout Guide，畫出熱迴路並說明它為什麼重要。

## 面試常問

> 先試著自己回答，再對照參考解答。

### Q1. Buck 的電感怎麼選？

1. 依 `ΔIL = (Vin − Vout) × D / (L × Fsw)` 選 L，使漣波電流約為 Iout 的 20～40%
2. 用**最大 Vin** 計算（漣波最大的條件）
3. **飽和電流 Isat** 要大於峰值電流，最好大於 IC 的限流值，並考慮高溫下降
4. **DCR** 越小損耗越低，但體積與成本上升
5. 溫升電流（Irms）要大於負載電流

### Q2. 為什麼負載暫態測試可以判斷穩定性？

負載電流瞬間變化相當於對控制迴路施加一個階躍輸入。迴路的阻尼由相位裕度決定：**相位裕度足夠時，輸出下陷後平滑回復；裕度不足時會出現多次振鈴**，振鈴次數越多、衰減越慢，裕度越差。它不能取代 Bode 量測，但能快速判斷。

### Q3. 客戶說 DC-DC 在輕載時有嘯叫聲，可能原因？

- 輕載進入 **PFM / 省電模式**，切換頻率降到 20Hz～20kHz 的音頻範圍
- **MLCC 的壓電效應**讓電路板振動發聲；電感線圈振動
- 對策：切換到**強制 PWM**、改用軟端子或較小封裝的 MLCC、換用屏蔽電感、調整負載使其不落在音頻範圍

### Q4. 開機時 DC-DC 打嗝、無法建立輸出電壓，怎麼排查？

1. 量輸出電壓與電感電流波形，確認是否**觸發 OCP 或 SCP**
2. 確認輸出電容總量是否超過 IC 可支援的範圍、負載是否在開機時就抽大電流
3. 加長 **Soft-start** 時間，或讓負載在 Power-Good 後才啟用
4. 檢查是否有 Pre-bias、UVLO 門檻與輸入電源能力（輸入電壓是否被拉垮）

### Q5. 如何降低 DC-DC 的 EMI？

- 縮小**熱迴路面積**，輸入小電容緊貼 IC
- 減少 SW 節點面積與振鈴：加 **RC Snubber**、Boot 電阻放慢上管開啟速度
- 使用**展頻**（Spread Spectrum）功能分散能量
- 輸入端加 π 型濾波、使用屏蔽電感
- 選擇 Fsw 避開敏感頻段（如 AM 廣播頻段，車用常見要求）

### Q6. LDO 的 PSRR 是什麼？為什麼重要？

**PSRR**（電源抑制比）表示 LDO 抑制輸入漣波傳到輸出的能力，單位 dB，例如 60dB 代表輸入漣波衰減 1000 倍。DC-DC 後接 LDO 給敏感電路時，要看 **DC-DC 切換頻率處的 PSRR**——很多 LDO 在高頻時 PSRR 大幅下降，可能無法有效濾除 MHz 級的切換漣波。

## 常見誤解

- **「輸出電容越大越穩」**：電容改變了迴路的極點與零點，可能讓迴路更不穩，且開機時更容易觸發 OCP。
- **「效率高就一定比較好」**：PFM 輕載效率高，但漣波與雜訊大，敏感應用要權衡。
- **「照 Datasheet 參考電路就沒問題」**：Layout、元件替換、實際負載特性都會影響結果，參考設計是起點不是保證。

## 本章回顧

- Buck 設計：D、ΔIL（20～40%）、Isat > Ipeak、輸出漣波、輸入電容 RMS
- 控制架構：電壓模式、電流模式、COT；輕載 PFM 與 FPWM 的取捨
- 穩定性：fc 約 Fsw 的 1/10～1/5、相位裕度 ≥ 45°，用負載暫態快速判斷
- 客訴前三名：振盪、開機打嗝、嘯叫 / EMI；Layout 熱迴路是關鍵
- 趨勢：USB PD EPR、AI 伺服器多相電源與 48V、PMBus 數位電源、GaN / SiC
