# 02. FAE 技術基本功：電源、時脈、訊號與量測

> **一句話**：客戶回報的問題，**八成以上最後是電源、時脈、訊號完整性、ESD 或散熱**，而不是晶片本身壞了。FAE 的技術核心就是讀懂規格書、正確量測，並快速判斷問題出在哪一層。

## 學習目標

- 讀懂 Datasheet 的關鍵章節：Absolute Maximum Ratings、Electrical Characteristics、時序圖、Layout Guide
- 掌握電源設計與除錯：LDO vs DC-DC、漣波、暫態響應、上電順序
- 排查石英振盪器、訊號完整性、ESD / EMC 與散熱問題
- 正確使用示波器與探棒，避免量錯
- 了解 Schematic / Layout Review 的檢查重點

> 前置知識：[SWEMindset 第 21 章](https://wyc915.github.io/SWEMindset/chapters/21-mcu-hardware)的電子學基礎與通訊介面。

## 1. Datasheet 怎麼讀才像 FAE 🟢

| 章節 | 重點 | 常見陷阱 |
|---|---|---|
| **Absolute Maximum Ratings** | 超過就可能**永久損壞**的極限 | 這不是工作範圍！設計要落在 Recommended Operating Conditions |
| **Recommended Operating Conditions** | 正常工作的電壓、溫度範圍 | 工業級（-40～85°C）與商規（0～70°C）差異 |
| **Electrical Characteristics** | Min / Typ / Max 數值 | **設計要用 Min / Max，不要用 Typ** |
| **Timing Diagram** | Setup / Hold time、上電時序 | 單位與量測條件（負載電容、溫度） |
| **Application / Layout Guide** | 參考電路、擺件與走線建議 | 客戶最常「省略」的地方 |
| **Errata（勘誤）** | 已知的晶片缺陷與 Workaround | **遇到怪問題先查 Errata** |

> 實務心法：客戶說「照 Datasheet 做了還是不行」，先逐項比對 **Reference Design 與客戶線路的差異**，問題常就在差異處。

## 2. 電源：最常見的問題來源 🟡

### 2.1 LDO vs DC-DC

| | LDO（線性穩壓） | DC-DC（切換式穩壓，如 Buck） |
|---|---|---|
| 原理 | 用電晶體「吃掉」多餘電壓 | 高速開關 + 電感儲能 |
| 效率 | 約 Vout / Vin，壓差大時很差 | 高（常見 85～95%） |
| 雜訊 | **低**，適合類比、RF、ADC 參考 | 有切換漣波與 EMI |
| 散熱 | 損耗 = (Vin − Vout) × I | 損耗小 |
| 成本 / 面積 | 便宜、小 | 需電感、較複雜 |

**計算範例**：5V 轉 3.3V、500mA 用 LDO，損耗 = (5 − 3.3) × 0.5 = **0.85W**，小封裝 LDO 很可能過熱觸發保護 → 客戶說「跑一陣子就重開機」。

### 2.2 電源除錯檢查表

| 現象 | 可能原因 | 怎麼確認 |
|---|---|---|
| 隨機重開機 | 負載暫態造成**電壓下陷**觸發 Brown-out Reset | 示波器觸發在電壓下降沿，看最低點 |
| ADC 讀值跳動 | 電源漣波、接地不良 | 量 ADC 參考電壓的 AC 雜訊 |
| 開機偶爾失敗 | **上電順序（Power Sequencing）**不符、Reset 釋放太早 | 多通道同時量各電源軌與 Reset 腳 |
| 插上就燒 / 保險絲斷 | 湧浪電流（Inrush）、反接、短路 | 電流探棒量開機瞬間電流 |
| DC-DC 嘯叫或發燙 | 電感飽和、輸出電容不足、迴路不穩 | 量 SW 節點波形、做負載暫態測試 |

**關鍵觀念**：
- **去耦電容（Decoupling）**要靠近電源腳，小電容（如 0.1µF）處理高頻、大電容處理低頻
- **MLCC 的 DC Bias 效應**：陶瓷電容加上直流電壓後，實際容值可能剩一半以下，要查廠商曲線
- **漣波量測**：探棒要用**彈簧接地針**，不要用長接地夾，否則量到的是天線收到的雜訊

## 3. 時脈與石英振盪器 🟡

晶片「不開機」「USB 不穩」「UART 亂碼」常是時脈問題。

- **負載電容**：Crystal 規格書的 CL，外部電容約為 `C1 = C2 ≈ 2 × (CL − C_stray)`，C_stray 通常估 2～5pF
- 電容選錯 → 頻率偏移（ppm 超標）→ UART 鮑率誤差、USB / 藍牙連不上
- **起振餘裕（Negative Resistance / Safety Factor）**：餘裕不足時低溫或老化後可能不起振
- **不要直接用一般探棒量 Crystal 腳**：探棒電容會改變負載甚至讓它停振，改量 MCU 的時脈輸出腳（MCO）或用低電容主動探棒

## 4. 訊號完整性（SI）🔴

當訊號邊緣很快（上升時間短），走線就要當成**傳輸線**看待。

| 問題 | 原因 | 對策 |
|---|---|---|
| **反射 / 振鈴（Ringing）** | 阻抗不匹配 | 串聯終端電阻（如 22～33Ω）、控制阻抗 |
| **串音（Crosstalk）** | 相鄰走線耦合 | 加大間距（3W 原則）、中間走地 |
| **時序偏移（Skew）** | 差動對或匯流排長度不等 | 等長繞線 |
| **地彈 / 回流路徑斷裂** | 走線跨越分割的地平面 | 高速訊號下方保持完整參考平面 |

- **高速介面**（USB、PCIe、DDR、MIPI、HDMI）有阻抗規範（如 USB 差動 90Ω、PCIe 85Ω），並用**眼圖（Eye Diagram）**判斷品質
- **DDR 問題**常與 Layout、終端、記憶體訓練參數有關；FAE 會協助客戶調整 DDR 參數或跑記憶體壓力測試
- 經驗法則：**示波器頻寬 ≈ 0.35 / 上升時間**，且至少為訊號主要頻率的 3～5 倍

## 5. ESD、EMC 與散熱 🟡

### 5.1 ESD 與 EMC

| 項目 | 說明 | 常見標準 |
|---|---|---|
| **ESD 系統級** | 人體或物體靜電打到產品 | **IEC 61000-4-2**（如接觸 ±8kV、空氣 ±15kV） |
| **ESD 元件級** | 晶片出廠的耐受度 | JEDEC / ANSI-ESDA：HBM、CDM |
| **輻射 / 傳導發射（EMI）** | 產品對外干擾 | CISPR 32、FCC Part 15 |
| **耐受度（EMS）** | 產品抗干擾 | IEC 61000-4-x 系列（EFT、Surge、RF 等） |

> 元件級 ESD（如 HBM 2kV）只保護晶片在**生產搬運**時不壞，**不代表產品能通過系統級 ESD**，接頭處仍需 TVS 二極體與良好的接地路徑。

**ESD 後當機常見處理**：TVS 擺放靠近接頭、縮短接地、加濾波、韌體加看門狗與狀態自我修復。

### 5.2 散熱

- **接面溫度**：`Tj = Ta + P × θJA`（Ta 環境溫度、P 功耗、θJA 熱阻）
- 例：Ta = 50°C、P = 1.5W、θJA = 40°C/W → Tj = 110°C，接近多數晶片 125°C 上限，需改善
- 對策：加大銅箔面積、散熱孔（Thermal Via）、散熱片、降頻或降低功耗
- 工具：**熱像儀**快速找熱點

## 6. 量測儀器與正確量法 🟢

| 儀器 | 用途 | FAE 注意事項 |
|---|---|---|
| **示波器** | 看電壓隨時間變化 | 頻寬、取樣率、探棒衰減比（1X / 10X）、**觸發設定** |
| **電流探棒** | 量開機湧浪、負載電流 | 使用前消磁與歸零 |
| **差動探棒** | 量浮接訊號（如 Buck 的 SW 節點、馬達驅動） | 不可用一般探棒的地夾接非地點，可能短路燒毀 |
| **邏輯分析儀** | 多通道數位訊號、協定解碼 | 只看 0 / 1，看不到電壓品質 |
| **電源供應器 / 電子負載** | 模擬電池、測試負載暫態 | 設定限流保護 |
| **頻譜分析儀** | EMI、RF 訊號 | 預掃描（Pre-scan）可在送實驗室前找問題 |
| **協定分析儀** | USB、PCIe、藍牙封包 | 看封包層級問題 |

**最常見的量錯**：
1. 用 15cm 長地夾量高頻訊號 → 看到假振鈴
2. 示波器頻寬限制沒關（或沒開）→ 誤判雜訊大小
3. 探棒沒做**補償校正**（方波校正訊號）→ 波形失真
4. 量錯參考點：「地」不是同一個地

## 7. Schematic 與 Layout Review 🟡

FAE 常在客戶打板前協助檢查線路，**前期發現問題比量產後便宜百倍**。

**Schematic 檢查重點**：
- 電源電壓、電流容量、上電順序符合規格
- 每個電源腳都有去耦電容
- Strapping / Boot 腳位的上下拉正確（決定開機模式）
- Reset 電路、時脈電路、未使用腳位的處理
- 介面電平匹配（1.8V / 3.3V 是否需要準位轉換）
- 預留除錯點：UART、SWD / JTAG、測試點

**Layout 檢查重點**：
- 去耦電容靠近腳位、電源迴路面積小
- DC-DC 的大電流迴路（輸入電容、開關、電感）緊湊
- 高速訊號阻抗控制、等長、參考平面完整
- 類比與數位區域分隔、Crystal 遠離干擾源
- 散熱焊盤（Exposed Pad）與散熱孔

## 8. 韌體與 SDK 支援 🟡

很多 FAE（尤其 MCU、SoC、無線晶片）的日常是軟體問題：

- 協助客戶**移植 SDK / BSP**、設定 Pin Mux、Device Tree（[SWEMindset 第 24 章](https://wyc915.github.io/SWEMindset/chapters/24-embedded-linux)）
- 解讀客戶 Log、重現問題、提供 Patch 或 Workaround
- 熟悉自家**燒錄工具、量產工具、除錯工具**
- 無線產品（Wi-Fi、藍牙）：吞吐量、連線穩定度、天線匹配、認證（如 FCC、NCC、藍牙 SIG）

> 這是軟體背景轉 FAE 的最大優勢：**能同時看懂波形與程式碼的 FAE 非常搶手**。

## 動手練習

1. **電源量測報告**：用 EVB 搭配可調電子負載（或用電阻 + MOSFET 自製負載切換），量測 3.3V 電源軌在負載跳變時的下陷與恢復時間，寫成一頁報告。
2. **探棒實驗**：同一個方波訊號，分別用長地夾與彈簧接地針量測，截圖比較振鈴差異。
3. **Datasheet 練習**：挑一顆 Buck 轉換器（如 TI 或 Richtek 的產品），依規格書計算電感與輸出電容，再與廠商線上設計工具（如 TI WEBENCH）結果比對。
4. **讀 Errata**：下載你常用 MCU 的 Errata 文件，找出 3 個會影響實際設計的問題與其 Workaround。

## 面試常問

> 先試著自己回答，再對照參考解答。

### Q1. 客戶說產品隨機重開機，你會怎麼排查？

1. **收集資訊**：發生頻率、環境（溫度、負載）、批次是否集中、韌體版本、能否重現
2. **區分 Reset 原因**：讀 MCU 的 Reset 原因暫存器（Brown-out、Watchdog、軟體重置、外部 Reset 腳）
3. **電源**：示波器觸發在電源下陷，看是否低於 BOR 門檻；檢查負載暫態（如 Wi-Fi 發射、馬達啟動）
4. **Watchdog**：若是看門狗重置，回到韌體找卡住的地方
5. **外部干擾**：ESD、EMI、接地；Reset 腳是否有雜訊
6. **交叉驗證**：換到 EVB 是否也會發生（A/B 測試），區分晶片問題或客戶線路問題

### Q2. LDO 和 DC-DC 怎麼選？

- 壓差小、電流小、對雜訊敏感（類比、RF、ADC 參考）→ **LDO**
- 壓差大、電流大、重視效率與電池續航 → **DC-DC**
- 常見組合：**DC-DC 先降壓，再接 LDO 給敏感電路**，兼顧效率與雜訊
- 一定要算 LDO 損耗 `(Vin − Vout) × I` 與溫升

### Q3. Absolute Maximum Ratings 和 Recommended Operating Conditions 有什麼不同？

- **Absolute Maximum**：承受的極限，超過可能永久損壞；**即使在範圍內也不保證功能正常**，長期接近極限會影響可靠度
- **Recommended Operating**：保證功能與規格的工作範圍，設計要落在這裡並保留餘裕

### Q4. 為什麼量測高頻訊號不能用長的探棒地線？

探棒地線形成一個**迴路電感**，與探棒電容產生共振，會在快速邊緣上產生**假的振鈴**；長地線也像天線，會收進周圍雜訊。應使用**彈簧接地針**或最短接地，必要時用主動探棒。

### Q5. 晶片通過 HBM 2kV，為什麼產品 ESD 測試還是會當機？

HBM 是**元件級**標準，模擬生產搬運時的靜電；產品測試的 IEC 61000-4-2 是**系統級**，能量與上升速度都高很多。系統級要靠 TVS、接地設計、外殼、Layout 以及韌體的自我恢復機制（看門狗、狀態檢查）共同達成。

### Q6. Crystal 不起振或頻率偏移，可能原因？

- 負載電容選錯（未考慮雜散電容）
- 起振餘裕不足（ESR 太大、驅動能力設定太低），低溫時更明顯
- Layout 走線太長、靠近雜訊源、下方沒有地
- 量測時探棒影響（量測本身讓它停振）
- 元件品質或焊接問題

### Q7. 如何判斷問題是晶片本身還是客戶設計？

1. **在原廠 EVB 上重現**：EVB 正常 → 傾向客戶設計
2. **ABA 交換測試**：把「好板的晶片」與「壞板的晶片」互換，看問題跟著晶片還是跟著板子
3. **比對 Reference Design** 與客戶線路、Layout、BOM 的差異
4. 跟著晶片走 → 送回原廠做**失效分析（FA）**，詳見[第 03 章](03-fae-business-support.md)

## 常見誤解

- **「Typ 值就是保證值」**：Typ 只是典型值，設計必須以 Min / Max 計算餘裕。
- **「示波器螢幕上看到的就是真的」**：探棒、接地、頻寬設定都會改變結果，**先懷疑量測方法**。
- **「電容就是電容」**：MLCC 有 DC Bias、溫度係數；電解電容有 ESR 與壽命，選錯會造成電源不穩。

## 本章回顧

- 讀 Datasheet：設計看 Recommended 與 Min / Max，怪問題先查 Errata
- 問題優先排查順序：**電源 → 時脈 → Reset → 訊號 → ESD / 散熱 → 韌體**
- 量測要正確：短接地、正確頻寬與觸發，先確認量測方法再下結論
- 能同時看懂波形與程式碼，是軟體背景 FAE 的核心競爭力
